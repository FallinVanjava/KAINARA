# Audit UI Panel Admin Kainara

Tanggal: 2026-11-22  
Cakupan: build Turbopack dan warna panel admin. Audit mode AFTER, belum ada file UI yang diubah.

## Temuan

1. **HIGH — Sidebar marun mendominasi panel desktop dan mobile.** `components/admin/admin-sidebar.tsx` memakai marun `#7A1212` sebagai seluruh permukaan 260px, dan `components/admin/admin-topbar.tsx` memakai warna sama untuk drawer mobile. Ini bertentangan dengan `DESIGN.MD` 60/30/10: krem/putih harus mendominasi, marun hanya blok tegas terpilih. Usulan: ubah permukaan sidebar menjadi putih/krem, teks marun; simpan marun pada penanda aktif atau CTA, emas hanya sebagai detail aktif.

2. **MEDIUM — Issue Turbopack tidak tereproduksi pada build saat ini.** `npm run build` memakai Next.js 16.4.6 Turbopack dan sukses, 27 rute. Belum ada pesan atau tangkapan layar tentang “issue 8”; temuan ini bukan klaim bahwa bug visual/runtime tidak ada. Untuk isolasi, perlu teks error atau langkah reproduksi dari panel.

3. **MEDIUM — Kontras beberapa warna teks sekunder perlu verifikasi sebelum perubahan palet.** Panel memakai `#7A3A3A` pada permukaan putih/krem dan emas `#96640F` pada elemen kecil. Perubahan warna berisiko menurunkan keterbacaan jika tidak dihitung dengan WCAG AA. Usulan: pertahankan warna teks yang lolos kontras; batasi emas ke ikon, garis, atau teks besar.

- Audit statis `DESIGN.MD` dan warna pada komponen admin: sidebar desktop dan drawer mobile menjadi area warna utama yang paling dominan.
- Belum dilakukan klik manual, pemeriksaan console browser, atau pengujian breakpoint.

Temuan 1 disetujui dan diperbaiki pada `components/admin/admin-sidebar.tsx` dan `components/admin/admin-topbar.tsx`: sidebar/drawer kini memakai permukaan krem, navigasi aktif memakai krem tua, marun dipertahankan untuk teks/identitas, emas menjadi aksen kecil. Temuan 2 dan 3 belum diubah.

Verifikasi pasca perubahan: `npm run lint` 0 error (2 warning existing pada hero), `npm run build` sukses dengan Turbopack (27 rute). Belum ada pengujian browser manual.

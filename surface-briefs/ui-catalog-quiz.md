# Surface: katalog, detail motif, dan kuis KAINARA

Scope: `/motif`, `/motif/[slug]`, `/kuis`. Landing page dan halaman admin tidak diubah.

Mode: Persuade (landing-adjacent katalog/detail) + Experience (kuis matching canvas).

Audience: pelajar, wisatawan, pencinta budaya; mayoritas mobile tapi dirancang desktop 1440px.

Job: menjelajahi motif Lampung, memahami filosofinya, dan menyelesaikan kuis pencocokan motif.

Task: navigasi katalog, detail motif bertematik editorial, kuis line-matching dengan animasi garis.

Direction contract:

- THESIS: KAINARA adalah platform edukasi tapis Lampung yang membiarkan motif bertutur lewat gambar tinggi dan warna masala. Melarang tampilan SaaS generik, gradien, neon, dan tumpukan komponen; landing page dipertahankan persis.
- OWN-WORLD: latar krem `#FCF8F3`, kartu putih hangat `#FEFEFE` dengan border `#E8DDD0`, brand marun `#6D0F0F` (hover `#540B0B`), aksen emas benang `#C8A84B`, judul Playfair Display, tubuh Plus Jakarta Sans, navigasi kaca lengkat, kartu bento dengan sudut organik rounded-3xl/rounded-2xl.
- STORY: pengunjung memahami dari pandangan pertama bahwa ini adalah tempat belajar tapis Lampung, lalu memilih katalog, detail motif, atau kuis dengan gerak yang diingat.
- FIRST VIEWPORT (katalog): header beranda dengan pencarian dan filter pilih daerah, grid bento empat kolom kartu motif (gambar tekstur kain, label asal, judul serif, pindai filosofi), border halus dan skema warna resmi.
- FIRST VIEWPORT (detail): dua kolom, kiri pratinjau kain besar + thumbnail sulam emas, kanan tag daerah, judul serif, kartu informasi filosofi/sejarah/etika dan rekomendasi padu padan.
- FIRST VIEWPORT (kuis): header serif "Kuis Pencocokan Motif Tapis", progress pill, instruksi; dua kolom kartu gambar motif dan nama motif dengan titik tunggul, overlay SVG garis kurva marun/emas, tombol Selesai.
- FORM: kuis dimainkan via tombol layar besar, koordinasi simpan hasil lembut, tidak ada gambar tanpa alternatif, target sentuh ≥44px.
- Seed reference: none (user pinned visual directive).
- FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
